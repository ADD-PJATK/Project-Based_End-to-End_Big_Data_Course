## Additional Assignment 4 — Secure AI Prompt + Mock Integration App (in-class)

**Format:** single lab session (~90 min): ~15–20 min repo prep → one-shot AI prompt → group discussion → instructor check after 30 min.

**Repository:** existing `sXXXXX_kafka` (push prior work to a backup branch; restructure `main` for AA4).

**Grading:** **10** base (any number of prompts during class) + **+5 bonus** if the mock works after **one** high-quality prompt.

**Submission (MS Teams):** two links — (1) Phase A commit URL, (2) repo URL with full AI chat in `documentation/ai-chat/`.

This assignment **spins together** AA1 + AA2 + Phase 2:

- sanitized **prompt** (no secrets),
- **local mock** stock API (offline),
- **anonymizer** integration,
- intentional bugs for the AI agent to fix.

Folder: `additional-assignment-4-secure-ai-mock-integration/` (`README.md`, `ACCEPTANCE.md`)
